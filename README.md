# Projets sélectionnés

Reconstruction 3D, automatisation et vérification formelle. Chaque projet ci-dessous donne accès au code et à un résultat à explorer.

### PRONTO · Reconstruction 3D par lumière structurée
Un prototype qui pilote une caméra et un vidéoprojecteur, traite les captures avec Python et OpenCV, puis produit un nuage de points visualisable dans le navigateur. L'interface d'acquisition est en C# / Windows Forms.

[Explorer les reconstructions 3D](https://math680.github.io/pronto-reconstructions-3d/) · [Voir le code et le pipeline](https://github.com/Math680/Pronto-Imageur-3D)

### Conway 99 · Formalisation et vérification avec Lean
Deux développements Lean et Mathlib formalisent des contraintes sur un graphe hypothétique. Le dépôt accompagne le préprint et documente les axiomes, les limites des résultats et la procédure de vérification.

[Lire le préprint](https://github.com/Math680/conway99-minimal-lean/blob/main/paper/Rannou_Conway99_Preprint.pdf) · [Examiner les preuves et leur vérification](https://github.com/Math680/conway99-minimal-lean)

### Telegram Codex Bridge · Automatisation sur Linux
Un service Python auto-hébergé relie Telegram à Codex CLI. Il utilise le long polling, des alias pour sélectionner les espaces de travail et un verrou qui limite l'exécution à une commande à la fois.

[Voir le code et la configuration](https://github.com/Math680/Telegram-Codex-Bridge)

### Inclusion Quest · Application web de jeu coopératif
Une adaptation d'un jeu de sensibilisation au handicap, jouable à plusieurs sur un écran partagé. Le plateau, les cartes, le chronomètre et le suivi des scores tournent dans le navigateur.

[Voir l'application et le plateau](https://github.com/Math680/InclusionQuest)
